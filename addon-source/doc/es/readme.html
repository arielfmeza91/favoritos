Favoritos para NVDA

Favoritos es un complemento para NVDA que permite guardar enlaces (páginas web), carpetas y accesos a archivos o programas, y acceder rápidamente a ellos desde un menú propio dentro de NVDA.

Dónde encontrar el complemento

Abre el menú de NVDA, entra en Herramientas y allí encontrarás el submenú Favoritos.

Añadir un elemento a favoritos

  1. Entra en el menú NVDA, Herramientas, Favoritos.
  2. Selecciona Añadir a favoritos...
  3. Se abrirá un diálogo donde debes elegir el tipo de elemento a añadir:
    • Enlace (sitio web): para guardar una dirección de internet (URL).
    • Carpeta: para guardar la ruta de una carpeta de tu equipo.
    • Acceso a archivo o programa: para guardar la ruta de un archivo o de un programa ejecutable.
  4. Escribe un nombre descriptivo para identificar el elemento en el menú.
  5. Escribe la URL o la ruta correspondiente. Si elegiste Carpeta o Acceso a archivo o programa, puedes usar el botón Examinar... para localizarla sin necesidad de escribirla a mano.
  6. Pulsa Aceptar para guardarlo.

Acceder a tus favoritos

Dentro del submenú Favoritos encontrarás tres submenús, uno por cada categoría:

  • Enlaces: lista de páginas web guardadas. Al seleccionar una, se abre en tu navegador predeterminado.
  • Carpetas: lista de carpetas guardadas. Al seleccionar una, se abre en el Explorador de archivos.
  • Accesos a archivos o programas: lista de archivos o programas guardados. Al seleccionar uno, se abre o se ejecuta con la aplicación predeterminada de Windows.

Si todavía no has añadido ningún elemento de una categoría, el submenú mostrará la opción deshabilitada "(No hay elementos)".

Editar o eliminar elementos

En el menú Favoritos, debajo de Añadir a favoritos..., hay una opción Editar o eliminar favoritos.... Al seleccionarla:

  1. Elige la categoría (Enlaces, Carpetas o Accesos a archivos o programas).
  2. Verás la lista de elementos guardados en esa categoría.
  3. Pulsa Editar... para cambiar el nombre o la URL/ruta del elemento seleccionado.
  4. Pulsa Eliminar para quitar el elemento seleccionado de favoritos.
  5. Pulsa Cerrar cuando termines.

Dónde se guardan los datos

Los favoritos se guardan en un archivo llamado favoritos.json dentro de la carpeta de configuración de tu perfil de NVDA, por lo que se mantienen entre reinicios de NVDA y del equipo.
