Favoritos for NVDA

Favoritos is an NVDA add-on that lets you save links (web pages), folders, and shortcuts to files or programs, and quickly access them from a dedicated menu inside NVDA.

Where to find the add-on

Open the NVDA menu, go to Tools, and you will find the Favoritos submenu there.

Adding an item to favorites

  1. Open the NVDA menu, Tools, Favoritos.
  2. Choose Add to favorites...
  3. A dialog will open where you choose the type of item to add:
    • Link (website): to save a web address (URL).
    • Folder: to save the path of a folder on your computer.
    • File or program shortcut: to save the path of a file or an executable program.
  4. Type a descriptive name to identify the item in the menu.
  5. Type the URL or path. If you chose Folder or File/program shortcut, you can use the Browse... button to locate it instead of typing it manually.
  6. For a link, choose in Open with the browser you want to use (by default, the Windows default browser). Other browser... lets you pick any program.
  7. Press OK to save it.

Adding the current web page

While in a browser (Chrome, Edge, Firefox, Brave, Opera, Vivaldi...), press NVDA+Shift+F. The add dialog opens with the page title and URL already filled in. It also works when focus is in the address bar. You can change the gesture in Preferences, Input gestures, Favoritos category.

Accessing your favorites

Inside the Favoritos submenu there is a Most used submenu and three category submenus:

  • Most used: up to 10 favorites from any category, ordered from most to least opened. It updates every time you open one.
  • Links: saved web pages. Selecting one opens it in the browser chosen for that link or, if none was chosen, in your default browser.
  • Folders: saved folders. Selecting one opens it in File Explorer.
  • File or program shortcuts: saved files or programs. Selecting one opens or runs it with the Windows default application.

If a category has no items yet, its submenu shows a disabled "(No items)" entry.

Editing or removing items

In the Favoritos menu, below Add to favorites..., there is an Edit or remove favorites... option. Selecting it lets you:

  1. Choose the category (Links, Folders, or File or program shortcuts).
  2. See the list of saved items in that category.
  3. Press Edit... to change the selected item's name, URL/path or, for links, browser.
  4. Press Remove to remove the selected item from favorites.
  5. Press Close when done.

Where data is stored

Favorites are stored in a file named favoritos.json inside your NVDA user configuration folder, so they persist across restarts of NVDA and your computer.
